Overview

Sentinel ingests a packet capture, matches every flow against real threat-intelligence indicators, and shows its work at every step. Nothing here happens off-screen — the activity log below is the same log the engine writes internally.

Pipeline

01 Ingest traffic
Read a .pcap file, reassemble flows, extract hostnames/URLs/hashes.
 Open
02 Signature sources
Fetch IOCs from ThreatFox / URLhaus, cached locally so nothing is called per packet.
 Open
03 Detections
Match every flow, classify Benign / Suspicious / Malicious, log would-block actions.
 Open
04 Report
Aggregate summary and a full JSON export of every detection.
